# BISINDO-ObjectDetection-YOLOModel

This project focuses on Indonesian Sign Language (BISINDO) object detection using YOLO-based models.
The system is designed to detect static BISINDO hand sign classes from images and video inputs
to support sign language recognition research.

## Dataset
- Total images: 473
- Number of classes: 19 (A–Z excluding J and R)
- Data type: Static hand sign images
- Annotation format: YOLO format

⚠️ The dataset is not included in this repository due to size limitations.
